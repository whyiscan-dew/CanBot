Binance API anahtarları

API anahtarı nasıl alınır? (adım adım)
  1. Önce Binance'te Vadeli (Futures) hesabını açın. Vadeli hesaptan önce oluşturulan anahtara Vadeli izni verilemez.
  2. Bilgisayarda: profil simgesi → Hesap → API Yönetimi. Telefonda: Binance Pro modu → Daha fazla → Diğer → API Yönetimi.
  3. API Oluştur → Sistem tarafından oluşturulan seçin, isim verin (ör. CanBot), doğrulamayı tamamlayın.
  4. API Key ve Secret Key'i hemen kopyalayın; Secret Key sonra tekrar gösterilmez.
  5. Kısıtlamaları düzenle → Yalnızca güvenilir IP'lere erişimi kısıtla seçip internet IP adresinizi ekleyin (Google'da “IP adresim”). Zorunlu: IP kısıtlaması olmadan Binance bu anahtara işlem izni vermez.
  6. Okumayı Etkinleştir ve Vadeli İşlemleri Etkinleştir kutularını işaretleyin. Para çekme iznini ASLA açmayın.
  7. API Key ve Secret Key'i buraya yapıştırıp Kaydet ve Bağlantıyı test et'e basın. Son olarak USDT'yi Spot'tan USDⓈ-M Vadeli cüzdana aktarın.
  8. Testnet için anahtarları Binance Demo Trading (demo.binance.com) / Futures Testnet sayfasından alın.

Risk seviyesi

Riski artırmak kârı değil, en çok kayıpları büyütür. Testlerde riskin iki katına çıkması, en büyük düşüşü %17'den %32'ye çıkardı.

Sanal hesap

Sanal modda gerçek fiyatlarla, para riske girmeden işlem yapılır. Sıfırlarsanız sanal bakiye ve sanal işlem geçmişi silinir.

Windows

Pencereyi kapattığınızda bot saatin yanındaki simgede çalışmaya devam eder. Tamamen kapatmak için simgeye sağ tıklayıp “Çıkış”ı seçin.

Hakkında

CanBot, Binance USDⓈ-M vadeli işlemlerde trend takibi yapan, her işleme borsada stop-loss koyan, günlük zarar ve en büyük düşüş limitleriyle kendini durdurabilen bir bottur. Geçmiş test sonuçları geleceği garanti etmez.
